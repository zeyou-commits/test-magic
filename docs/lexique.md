# Lexique BledWay

Un mot par idée, dans le site comme dans l'espace équipe.

| Mot | Sens | À éviter |
|---|---|---|
| Ligne | Un trajet entre deux ports, dans un sens | Liaison |
| Traversée | Le voyage en mer d'un départ à une arrivée | Trajet, voyage en mer |
| Départ | Le moment où un navire quitte le port | |
| Arrivée | Le moment où il atteint le port | |
| Navire | Le ferry lui-même | Bateau |
| Compagnie | L'armateur qui vend le billet | Opérateur |
| Port | Le lieu de départ ou d'arrivée | Terminal |
| Aller, Retour | Le sens du voyage | |
| Trouver | Chercher une traversée | Chercher, Réserver |
| Route | Le trajet en voiture jusqu'au port | Itinéraire |
| Loupe | Retrouver un navire, un port, une compagnie | Repérer |
| Suivre | Recevoir les nouvelles d'un navire ou d'un départ | S'abonner |
| Signaler | Dire ce qu'on voit sur place | Remonter |
| Alerte | Information grave sur un navire | Flash, pour une alerte |
| Durée | Temps d'une traversée | Temps de trajet |

`deName()` dans `src/lib/ferry/format.ts` gère « de » et « d' » devant un nom propre.

## La voix de la 504

La 504 est la voiture de la famille qui fait la route du bled. Elle parle dans les bulles `Bw504Note` (et l'encart `BwKnow`), jamais ailleurs.

1. Elle dit « je » et tutoie, toujours. Le reste du site vouvoie ; « nous » est la voix de l'équipe.
2. Elle est la voiture, jamais le navire : elle voyage dans le navire, garde un œil sur lui, et dit « navire », jamais « bateau ».
3. Elle ne promet que ce qu'un mécanisme du site fait, et dit la condition (« avec les notifications »).
4. Elle n'invente aucune raison : ce que les données prouvent, sinon « je ne sais pas ».
5. Elle dit pourquoi on pose une question ; la règle de droit, avec sa source, va dans « Bon à savoir ».
6. Elle vit dans la page, à trois moments : page vide, blocage (la raison et une sortie), réussite. Jamais de fenêtre au chargement.
7. Un seul visage qui parle : `/cabas/persos/voiture_504.webp`. L'icône plate reste l'icône de l'application.
