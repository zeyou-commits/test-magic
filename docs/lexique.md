# Lexique BledWay

Un mot par idée, dans le site comme dans l'espace équipe.

| Mot | Sens | À éviter |
|---|---|---|
| Ligne | Un trajet entre deux ports, dans un sens | Liaison |
| Traversée | Le voyage en mer d'un départ à une arrivée | Trajet, voyage en mer |
| Départ | Le moment où un navire quitte le port | |
| Arrivée | Le moment où il atteint le port | |
| Navire | Le ferry lui-même | Bateau |
| Compagnie | L'armateur qui vend le billet | Opérateur |
| Port | Le lieu de départ ou d'arrivée | Terminal |
| Aller, Retour | Le sens du voyage | |
| Trouver | Chercher une traversée | Chercher, Réserver |
| Route | Le trajet en voiture jusqu'au port | Itinéraire |
| Loupe | Retrouver un navire, un port, une compagnie | Repérer |
| Suivre | Recevoir les nouvelles d'un navire ou d'un départ | S'abonner |
| Signaler | Dire ce qu'on voit sur place | Remonter |
| Alerte | Information grave sur un navire | Flash, pour une alerte |
| Durée | Temps d'une traversée | Temps de trajet |

`deName()` dans `src/lib/ferry/format.ts` gère « de » et « d' » devant un nom propre.
